Elastic Two Body Scattering

using KeldyshContraction

System

The interaction action of elastic two-body scattering is

\[S_\mathrm{int} = -\frac{g}{2} \int d^d x \, [ (\bar{\phi}_+\phi_+)^2 - (\bar{\phi}_-\phi_-)^2 ].\]

This is the standard local interaction for s-wave bosonic scattering. In the RAK basis,

\[S_\mathrm{int} = -\frac{g}{2} \int d^d x \, [\bar{\phi}_c\bar{\phi}_q(\phi_c^2+\phi_q^2) +\phi_c\phi_q(\bar{\phi}_c^2+\bar{\phi}_q^2)].\]

@qfields ϕ::Boson
c, q = ϕ[Classical], ϕ[Quantum]

elastic2boson = -(
    (1 // 2) * (c^2 + q^2) * bar(c) * bar(q) + (1 // 2) * c * q * (bar(c)^2 + bar(q)^2)
)
L_int = InteractionLagrangian(elastic2boson, :g)

\[- \frac{1}{2} \phi^c \phi^c \bar{\phi^P} \bar{\phi^c} - \frac{1}{2} \phi^P \phi^P \bar{\phi^P} \bar{\phi^c} - \frac{1}{2} \phi^P \phi^c \bar{\phi^c} \bar{\phi^c} - \frac{1}{2} \phi^P \phi^c \bar{\phi^P} \bar{\phi^P}\]

The normalization identity $Z=1$ is enforced by the Wick-contraction machinery and is covered by the package's diagrammatic tests. The supported user workflow starts from the interaction and constructs the requested propagator correction with static perturbation order and edge count.

First order

G1 = DressedPropagator(L_int, Val(1), Val(3))
Σ1 = SelfEnergy(G1)
Self Energy:
keldysh:  
retarded: (0//1 + 1//1*im)*Gᴷ(y₁,y₁)
advanced: (0//1 + 1//1*im)*Gᴷ(y₁,y₁)

For this elastic interaction the first-order self-energy has no collision contribution: $Σ^K=0$ and $Σ^R=Σ^A$. The nontrivial elastic Boltzmann kernel appears at second order.
