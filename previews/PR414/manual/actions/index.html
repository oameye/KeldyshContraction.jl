Actions and interactions

InteractionLagrangian turns a symbolic field expression into a perturbative interaction vertex. The expression must be conserved, physical, and contain both Keldysh components.

@qfields ϕ::Boson
c, q = ϕ[Classical], ϕ[Quantum]

elastic = -(1 // 2) * ((c^2 + q^2) * bar(c) * bar(q) + c * q * (bar(c)^2 + bar(q)^2))
L = InteractionLagrangian(elastic, :g)
KeldyshContraction.InteractionLagrangian — Type
struct InteractionLagrangian{C<:Number, S<:KeldyshContraction.Statistics} <: KeldyshContraction.Lagrangian

Represents an interaction Lagrangian.

Fields

  • lagrangian: The Lagrangian expression

  • families: Physical field families appearing in the interaction

  • position: The position of the interaction Lagrangian

  • parameter: Canonical perturbation-parameter monomial

Constructor

Constructs an InteractionLagrangian from a symbolic Keldysh field expression.

Requirements

The expression must:

  • be a bulk term (is_bulk);
  • be conserved (is_conserved);
  • be physical (is_physical);
  • contain both Keldysh components.
source

The second argument labels the perturbative parameter. Distinct physical processes can be added directly,

@syms g γ
L = InteractionLagrangian(elastic, g) + InteractionLagrangian(loss, γ)

and remain separated into g, γ, g^2, gγ, and γ^2 sectors at higher order. @syms and arguments are re-exported from SymbolicUtils for symbolic parameter expressions and generic symbolic-tree interoperability; ordinary package workflows should prefer the semantic accessors below over inspecting result storage through arguments.

For interactions involving several physical field families, select the external family with the target keyword when constructing a propagator. The stable provenance accessors are:

KeldyshContraction.field_families — Function
field_families(x)

Return the physical field families carried by an interaction.

source
KeldyshContraction.target_family — Function
target_family(x)

Return the physical field family selected for the external two-point function or kinetic result.

source
KeldyshContraction.parameters — Function
parameters(x)

Return the perturbative parameter monomial, or the available monomials for a multi-process result.

source

The ordinary user should not manipulate LagrangianSum or perturbative bookkeeping containers directly; addition, indexing by parameter expressions, and the high-level propagator constructors provide the supported interface.

See Perturbation theory and self-consistency for the diagrammatic meaning of the perturbative sectors.
